# ERVA: Explicit Rule-Verification Agent for ARC-AGI-2

This repository contains the theoretical framework for ERVA, a failure-driven abstraction escalation agent for ARC-AGI-2.

## Project Overview
ERVA reframes failure as a diagnostic signal. It decomposes abstract reasoning into five auditable stages, culminating in a novel mechanism: failure-driven abstraction escalation.
